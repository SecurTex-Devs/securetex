🔒 Seguridad
  • Zip-slip: cada entrada se normaliza y se rechaza si contiene rutas absolutas, .. o enlaces simbólicos (T-F02).
  • Zip-bomb: se limitan el tamaño descomprimido, el ratio de compresión y el número de entradas (T-C05).
  • Cada archivo se analiza con ClamAV antes de estar disponible; hasta entonces no es descargable ni compilable (T-F05, fail closed).
  • El tipo real se detecta por magic bytes, nunca por la extensión.
