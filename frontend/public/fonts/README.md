Las licencias SIL OFL 1.1 están en los archivos `OFL-*.txt` de esta carpeta. Procedencia:

- https://github.com/google/fonts/tree/main/ofl/geist
- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
